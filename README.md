|---|---|
| Forward Pass | Generates predictions |
| Loss Calculation | Measures prediction error |
| Backpropagation | Calculates gradients |
| `zero_grad()` | Clears previous gradients |
| `backward()` | Computes gradients |
| `optimizer.step()` | Updates model parameters |
| Learning Rate | Controls parameter update size |
| Epoch | One complete pass through the dataset |
| Batch | Subset of training data |
| Iteration | One training step for a batch |
